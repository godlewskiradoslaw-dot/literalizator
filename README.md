# literalizator
iteralizator – polska gra słowna w stylu Literalnie. Codziennie 3 hasła na rosnących poziomach trudności, punktacja liter jak w Scrabble i premia za szybkość odgadnięcia. Pełny słownik ok. 35 tys. słów, statystyki dzienne, tygodniowe i miesięczne, tryb treningowy i dźwięki. Działa w przeglądarce telefonu, bez instalacji.
